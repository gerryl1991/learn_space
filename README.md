# LearnSpace — Student Learning Hub

**Learn smarter. Grow together.**

## Project Overview

LearnSpace is a responsive, student-focused website designed to support learners in developing effective study habits, improving their academic skills, and working towards their educational goals.

The website provides students with accessible learning resources, information about the LearnSpace initiative, and a contact interface. It was developed as part of a group assignment focused on responsive client-side web development and AI-assisted development practices.

The project emphasises usability, accessibility, responsive layouts, semantic HTML, and maintainable CSS.

## Objectives

The main objectives of LearnSpace are to:

- Provide students with accessible study resources and practical learning guidance.
- Present information about the LearnSpace initiative, its mission, and the students it supports.
- Deliver a consistent and user-friendly experience across desktop, tablet, and mobile devices.
- Apply responsive web design principles using HTML5 and CSS3.
- Demonstrate collaborative development and responsible use of AI-assisted tools.

## Website Pages

The website consists of four main pages.

| Page                             | Description                                                                                                                                     |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Home** (`index.html`)          | Introduces LearnSpace and highlights its purpose and key features.                                                                              |
| **About** (`about.html`)         | Explains the LearnSpace mission, intended audience, and approach to student learning.                                                           |
| **Resources** (`resources.html`) | Presents study guidance covering topics such as time management, exam preparation, assignment planning, goal setting, and healthy study habits. |
| **Contact** (`contact.html`)     | Provides a front-end contact interface for users.                                                                                               |

## Technologies Used

- **HTML5:** Provides the semantic structure and content of the website.
- **CSS3:** Controls the layout, visual presentation, typography, and responsive behaviour.
- **Flexbox:** Arranges page sections, navigation elements, and resource cards.
- **CSS Media Queries:** Adapt layouts to different screen sizes.
- **Google Fonts-compatible local font asset:** The project includes a local Roboto font file for consistent typography without relying on a remote font request.
- **Git and GitHub:** Support version control and collaborative development.
- **AI-assisted development tools:** Support selected stages of planning, implementation, review, and refinement.

The website uses vanilla HTML and CSS without a JavaScript framework. The mobile navigation uses a CSS-only checkbox approach.

## Key Features

### Responsive Design

The layout is designed to accommodate mobile phones, tablets, and desktop screens. CSS media queries adjust navigation, card arrangements, and page layouts according to screen width.

### Consistent User Interface

Shared styling provides consistent typography, colours, spacing, navigation, buttons, and footer presentation across the website.

### Student Learning Resources

The Resources page presents practical guidance to help students organise their studies, prepare for examinations, plan assignments, set academic goals, and maintain healthy study habits.

### Accessible and Semantic Structure

Semantic HTML elements help organise content clearly. Images include alternative text, and form fields use labels to communicate their purpose.

### CSS-Only Mobile Navigation

The mobile navigation uses HTML and CSS rather than JavaScript to control the menu's appearance and behaviour on smaller screens.

## Getting Started

### Prerequisites

You need:

- A modern web browser, such as Google Chrome, Microsoft Edge, or Firefox.
- A code editor, such as Visual Studio Code, if you want to inspect or modify the source files.
- Git, if you want to clone the project repository.

No package installation or build process is required for the static website.

### Running the Website Locally

1. Clone the repository or download the project files.
2. Open the project folder in your preferred code editor.
3. Confirm that the HTML pages, CSS files, images, and font assets are in their expected locations.
4. Open `index.html` in your browser.
5. Navigate between the pages using the website navigation.

For a more convenient development workflow, you can use the Live Server extension in Visual Studio Code.

## Responsive Testing

The website should be checked at the screen widths specified in the assignment.

| Viewport                       | Testing focus                                                                       |
| ------------------------------ | ----------------------------------------------------------------------------------- |
| **375px — Mobile**             | Verify that navigation, text, images, cards, and form fields fit within the screen. |
| **768px — Tablet**             | Check navigation alignment, card arrangements, spacing, and readability.            |
| **1200px and wider — Desktop** | Verify the desktop layout, content alignment, spacing, and overall presentation.    |

Testing should also confirm that:

- No unintended horizontal scrolling occurs.
- Images resize within their containers.
- Flexbox layouts reorganise appropriately at smaller screen sizes.
- The CSS-only mobile menu opens and closes correctly.
- Navigation links point to the correct pages.
- Important content remains visible and readable.

## Project Scope and Limitations

LearnSpace is a front-end website developed to demonstrate responsive client-side web development.

The contact page presents a user interface only. It does not include a backend service or message-processing system, so submitting the form does not send a message to a recipient.

The website does not currently require a database, server-side application, or user authentication system.
